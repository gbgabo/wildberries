## Installation

1. On the Start Page head to Options
2. Scroll down for the theme selection -> Set to Custom
3. Replace the colors with:

| Color      | HEX     |
|------------|---------|
| Background | #19002E |
| Text       | #FF0E82 |
| Primary    | #C79BFF |
| Success    | #00FFB7 |
| Warning    | #FFD700 |
| Danger     | #D70040 |

## Installation
1. Download the config.toml on this page
2. Place it on your config/rio location (in linux: .config/rio/config.toml)
3. After saving it, it should apply right away, if not -> restart Rio

## Troubleshooting
1. Rio will prompt you with the error message
2. Submit an issue if its source code related

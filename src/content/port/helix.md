## Installation

1. Download the wildberries.toml on this page
2. Place it on ~/.config/helix/themes
3. Should work on next open

## Troubleshoot

1. If it doesn't apply, when inside helix type :theme wildberries
2. It'll show you the error you might be encountering
3. Make an issue if it's source code bug
